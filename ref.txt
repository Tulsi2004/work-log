# Work Management System – Development Prompt

## Objective

Build a modern, simple, and scalable **Work Management System** that serves as a personal productivity and work journal. The primary goal of this application is to replace Excel sheets and Word documents by providing a centralized platform to record daily work, manage projects, track attendance, and maintain a searchable history of all completed tasks.

The application should be designed with scalability in mind so that additional features such as AI-generated reports, analytics, screenshots, documents, and team collaboration can be added in future versions.

---

# Tech Stack

Use the following technologies:

* Next.js (Latest App Router)
* TypeScript
* PostgreSQL
* Prisma ORM
* Tailwind CSS
* shadcn/ui
* React Hook Form
* Zod
* TanStack Table
* TanStack Query

The project should follow clean architecture with reusable components, proper folder structure, and scalable coding practices.

---

# Version 1 Scope

Keep the first version intentionally simple.

Do **not** build analytics, AI, dashboards with dozens of charts, notifications, calendars, or team collaboration yet.

The objective is simply:

> "Record every day's work and retrieve it easily in the future."
